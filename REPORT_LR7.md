# Лабораторная работа 7

## Вариант

Город по варианту: Калуга.

Индивидуальное задание: вариант 1 - добавить на карту подписи и сделать для подписей тянущуюся подложку.

## Выполнение задания

1. Создано картографическое веб-приложение на React + TypeScript с использованием MapGL JS API от 2ГИС. За основу взят шаблон React-приложения с картой 2ГИС.

2. В приложение подключен стиль карты 2ГИС. Для этого в параметрах создания карты указан идентификатор стиля:

```tsx
style: '5be90997-755f-4127-b003-f8c0e2d2cce9'
```

Также подключен демо-ключ MapGL JS API:

```tsx
key: '98ba98a4-edaa-4d4c-ade3-cc41f0820be0'
```

3. Центр карты перемещен в город Калуга. Координаты заданы в формате MapGL `[долгота, широта]`:

```tsx
export const MAP_CENTER = [36.261215, 54.513845];
```

4. Для публикации на GitHub Pages в `package.json` добавлено поле:

```json
"homepage": "https://bebrakaa.github.io/GIS_7laba"
```

Также добавлены команды:

```json
"predeploy": "npm run build",
"deploy": "gh-pages -d build"
```

5. Для региона по варианту использован GeoJSON-файл ДТП по Калужской области:

```text
src/data/kaluzhskaia-oblast.json
```

Изначальный файл был сокращен с 15384 до 1000 происшествий, чтобы приложение быстрее собиралось и не публиковало слишком большой датасет в репозиторий.

6. GeoJSON-данные подключены в React-приложении:

```tsx
import geoData from './data/kaluzhskaia-oblast.json';
```

Затем данные передаются в источник MapGL:

```tsx
new mapgl.GeoJsonSource(map, {
    data,
    attributes: {
        visible: true,
    },
});
```

7. Для промежуточного этапа был предусмотрен слой с точками ДТП из GeoJSON. В качестве подписи выбран не пример из методички, а более содержательное поле `severity` - тяжесть ДТП. Это позволяет отличать события по уровню последствий.

8. В финальной версии точечный слой заменен на тепловую карту ДТП. Тепловой слой показывает концентрацию ДТП: слабая плотность отображается бирюзовым цветом, средняя - желто-оранжевым, высокая - красным. Для слоя настроены `radius`, `intensity`, `opacity` и цветовая шкала через `heatmap-density`.

9. Индивидуальное задание выполнено с помощью `mapgl.Label`. На карту добавлены подписи для ДТП в городе Калуга. Подпись содержит категорию ДТП, тяжесть, количество пострадавших, количество погибших и погоду. Для подписи используется тянущаяся подложка с параметрами `stretchX`, `stretchY` и `padding`, поэтому фон подписи растягивается под размер текста.
